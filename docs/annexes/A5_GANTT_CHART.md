## 4. 各职能并行工作流

### 4.1 硬件 (HW) 工作流

```
M3───M5: SoC评估板 + Sensor POC + 充电POC
M6───M8: 原理图 → PCB → 打样 → Bring-up → 改版
M9───M12: 协助模具 + 可靠性测试 + EMC整改
M13──M15: 治具开发 + 产线导入
M16──M18: 量产支持 + 二代预研
```

### 4.2 结构 (ME) 工作流

```
M3───M5: DFM评审 + 热仿真 + 3D打印手板
M6───M9: EVT结构件(3D打印) + 堆叠验证
M10──M13: 模具T0/T1/T2 + CMF打样 + IP54密封验证
M14──M15: 产线装配SOP + 包装跌落验证
```

### 4.3 软件 (SW) 工作流

```
M3───M5: AI Pipeline POC + BSP预研
M6───M12: BSP定制 + 应用固件 + OTA + AI端侧部署
M10──M15: App开发(Flutter) + 云端全量上线
M16──M18: OTA首版 + 数据运营 + Bug修复
```


### 4.4 AI/算法 工作流

```
M3───M5: 云端POC(Whisper+GPT-4V+自动剪辑)
M6───M9: 端侧模型训练(人脸/VAD/场景) + RKNN量化
M10──M15: 云端Pipeline生产化 + RAG系统 + 成本优化
M16──M18: A/B测试 + 模型迭代 + 用户反馈闭环
```

### 4.5 品质 (QA) 工作流

```
M6───M9: EVT测试矩阵 + Bug管理
M10──M13: 可靠性测试 + EMC + 认证配合
M14──M15: FCT治具验证 + OQC标准执行 + 良率攻关
M16──M18: 售后数据分析 + 持续改善
```

### 4.6 供应链 (SCM) 工作流

```
M3───M5: 关键料Lead Time调查 + 二供识别
M6───M9: 关键料下PO + AVL建立
M10──M13: 量产物料齐套确认 + 安全库存建立
M14──M18: 持续供货 + Cost Down
```

### 4.7 市场 (MKT) 工作流

```
M1───M2: PMF验证 + 社交媒体蓄水
M3───M9: 品牌建设 + KOL关系维护 + 内容生产
M10──M14: 众筹页面制作 + 预售启动
M15──M18: 正式发售 + 全渠道运营 + 用户社区
```

## 8. 每周/每月管理节奏

### 8.1 每周

| 会议 | 时间 | 参会人 | 输出 |
|---|---|---|---|
| 全员 Standup | 周一 9:30 | 全员 | 本周目标 + 风险 |
| HW Review | 周三 14:00 | EE/ME/QA | 硬件进展 + 问题 |
| SW/AI Review | 周四 14:00 | SW/AI/PM | 软件进展 + Demo |
| PM 周报 | 周五 17:00 | PM → CEO | 邮件：进度/风险/决策项 |

### 8.2 每月

| 会议 | 内容 |
|---|---|
| 月度 Review | 甘特图更新 + 预算 vs 实际 + 风险矩阵 |
| 投资人 Update | 1 页 PPT：里程碑完成度 + 资金使用 + 下月计划 |
| Cost Review | BOM 成本追踪 + 降本机会识别 |

### 8.3 Gate 评审

每个 Gate 的评审流程：
1. Owner 提交 Gate Review 材料（提前 3 天）
2. 全员评审会（2 小时）
3. 逐项打分（GO / Conditional GO / KILL）
4. CEO 最终决策签字
5. 会议纪要归档

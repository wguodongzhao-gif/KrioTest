| 参数 | 推测 |
|------|------|
| 续航 | 12h（间歇使用） |
| SoC 功耗 | Snapdragon W5 Gen 2 典型 200-400mW |
| 推测容量 | 300-450mAh（基于 32g 总重和 12h 续航反推） |
| 类型 | 锂聚合物，异形定制 |
| 电压 | 3.85V |

**推算逻辑**：
- 32g 总重 - PCB/SoC(~7g) - 壳体(~6g) - 镜头(~2.5g) - 磁铁(~2g) - 其他(~3g) ≈ **电池约 11-12g**
- 锂聚合物能量密度约 250-280 Wh/kg → 11g ≈ **380-420mAh**
- 与 12h 续航 + W5 低功耗特性吻合

## 4. 利润模型推算

| 项目 | 金额（$） | 占售价比 |
|------|----------|---------|
| **终端售价** | $199 | 100% |
| COGS（BOM+制造） | -$54 | 27% |
| **硬件毛利** | $145 | 73% |
| 渠道/物流/退换（~30%） | -$60 | 30% |
| 研发摊销（首年 10K 台） | -$30 | 15% |
| 营销获客 | -$25 | 13% |
| 云端 AI 服务成本（年均/台） | -$15 | 8% |
| **净利润（估）** | **$15** | **~8%** |

**分析**：
- 73% 的硬件毛利率在 AI 硬件品类中**非常高**——得益于 Qualcomm W5 平台的高集成度（Wi-Fi/BT/ISP 全集成，省掉大量外围芯片）
- 真正的利润压力来自**云端 AI 服务成本**——如果用户活跃度高，LLM/存储/计算成本可能远超 $15/台/年
- Looki 目前没有强制订阅（基础功能免费），说明他们在用**硬件利润覆盖早期 AI 成本**，赌的是规模效应

## 5. 成本结构深度分析

### 5.1 Looki L1 的成本优势从何而来？

| 优势点 | 原因 | 对我们的启示 |
|--------|------|-------------|
| **SoC 高度集成** | Snapdragon W5 Gen 2 集成了 CPU/GPU/DSP/ISP/WiFi/BT 全部功能，极大减少外围元件 | 选型时优先考虑高集成度 SoC |
| **无屏幕** | 省掉了显示模组（$5-15）和相关驱动IC | 我们方案C同样无屏，一致 |
| **定焦镜头** | 无 AF 马达，模组极简 | 穿戴相机定焦是正确选择 |
| **无扬声器**（推测） | 仅靠振动+LED反馈，省掉音腔设计 | 可借鉴 |
| **磁吸挂绳充电** | USB-C 在挂绳上而非机身，机身密封更简单 | 聪明设计——机身零开孔 |
| **PC 壳体** | 注塑成本远低于 CNC 铝合金 | 与我们方案一致 |

### 5.2 Looki L1 的成本压力在哪？

| 压力点 | 分析 | 对我们的启示 |
|--------|------|-------------|
| **Qualcomm 芯片溢价** | QC 平台比国产方案（RV1126/Sigmastar）贵 $5-8 | 我们用国产 SoC 可进一步降本 |
| **IP67 成本** | 比 IP54 贵约 $1-2/台（更严格的密封+测试） | IP54 对我们够用且更便宜 |
| **3 麦克风** | 比单/双麦多 $0.4-0.8 | 3 麦确实是好选择（降噪+空间感） |
| **32GB eMMC** | 比 16GB 贵 $1.5 | 32GB 是合理选择（4K 照片很占空间） |
| **海星异形壳** | 比常规圆形/方形壳模具贵 10-20% | 造型复杂度 = 模具成本 |

### 5.3 成本对比：Looki L1 vs 我方方案 C（鹅卵石精灵）

| 模块 | Looki L1 | 我方方案 C | 差异 | 原因 |
|------|----------|-----------|------|------|
| SoC | $14（QC W5 Gen2） | $9.5（RV1126） | **-$4.5** | 国产替代 |
| 存储 | $3.5（32GB） | $7.5（64GB） | **+$4.0** | 我方选更大存储 |
| 摄像头 | $5.5（12MP 无名） | $6.5（IMX415 8MP） | **+$1.0** | 我方选更好 sensor |
| 防水 | $0.8+工艺$1（IP67） | $0.5+工艺$0.5（IP54） | **-$0.8** | 降级但够用 |
| 壳体 | $2.5（海星异形） | $2.0（鹅卵石简约） | **-$0.5** | 更简单的模具 |
| **总差异** | **$54** | **$52** | **-$2** | 基本持平 |

**结论**：我方用国产 SoC 省下的钱，投入到了更大存储和更好 Sensor 上，总成本基本打平。

## 6. 关键学习点（给创始人）

### 6.1 Looki 的商业智慧

| # | 学习点 | 说明 |
|---|--------|------|
| 1 | **$199 定价精准** | $54 COGS × 3.7 倍 = $199，留出足够空间覆盖渠道+研发+AI成本 |
| 2 | **无订阅不等于不赚钱** | 73% 硬件毛利已经很高，早期靠硬件养活，后期再开订阅 |
| 3 | **高集成 SoC 是小型化关键** | QC W5 一颗芯片解决 90% 的功能，这是做到 32g 的根本 |
| 4 | **USB-C 在挂绳不在机身** | 天才设计——机身零开孔 = 防水简单 + 成本低 + 外观干净 |
| 5 | **IP67 是营销加分项** | 实际穿戴场景 IP54 就够用，IP67 是为了"安心感"和差异化卖点 |
| 6 | **12h 续航的秘密** | W5 Gen 2 的 4nm 制程 + 间歇工作模式（不是一直录） |
| 7 | **不做屏幕是正确的** | 省成本 + 省电 + 保持极简 + 逼用户去 App 看（增加 App 粘性） |

### 6.2 我们可以进一步优化的空间

| 优化方向 | 预估节省 | 风险 |
|----------|---------|------|
| 用 Sigmastar SSC8836 替代 RV1126 | -$3~5/台 | ISP 能力弱一档 |
| 存储降到 32GB（同 Looki） | -$4/台 | 录制时长减半 |
| 磁吸充电（学 Looki 挂绳 USB-C 方案） | -$0.5/台 + 简化密封 | 需设计挂绳 |
| IP54 → IPX4（进一步降级） | -$0.3/台 | 营销卖点弱化 |
| **总可优化空间** | **$8-10/台** | 需 trade-off |

如果全部优化：COGS 可从 $52 降至 **$42-44**，支撑 **¥999-1299** 售价带。

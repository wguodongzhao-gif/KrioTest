## 6. 芯片选型策略深度分析

### 6.1 为什么用独立 GX8002 语音芯片？

**关键洞察**：Snapdragon W5 自己有 Hexagon DSP 可以做语音唤醒，为什么还要额外加一颗国芯微 GX8002？

| 可能原因 | 分析 |
|----------|------|
| **功耗**（最可能） | GX8002 功耗极低（<1mW 待机监听），让 W5 主 SoC 完全睡眠，只在唤醒后才上电 → 续航从 6h → 12h |
| **唤醒速度** | GX8002 always-on 监听，检测到唤醒词后 <100ms 唤醒主 SoC |
| **隐私** | 唤醒前不采集/上传任何音频数据，GX8002 只做本地 VAD/KWS |
| **成本 vs 功耗权衡** | 加 $2 芯片但省了更大电池（$3-5），且获得 12h 续航 |

**对我方的启示**：如果我们也想做 12h+ 续航 + always-on 语音唤醒，**必须有独立的低功耗语音前端**，不能靠主 SoC 硬扛。国芯微 GX8002 或同级（思必驰/云知声/探境）是必选。

### 6.2 为什么用 Azoteq IQS7211E 触控？

**关键洞察**：Looki L1 表面没有屏幕，为什么需要 trackpad 级别的触控 IC？

| 推测 | 说明 |
|------|------|
| **海星"身体"就是触控面** | 用户可以通过在外壳表面滑动/点触来交互（类 Humane AI Pin 的 touchpad） |
| **手势识别** | 单指点击 = 拍照，双指捏 = 特殊功能，滑动 = 切换模式 |
| **替代物理按键** | 减少开孔 → 更好的 IP67 密封 |

**对我方的启示**：如果我们的方案 C（鹅卵石精灵）要做"整面触压按键"，IQS7211E 是一个验证过的选择。

### 6.3 为什么用旗舰 IMU ICM-42688-P？

**关键洞察**：这颗 IMU 的 Mouser 单价 $3.87（1K量），在穿戴设备里属于"奢侈"选择——普通穿戴用 BMI270（$1.5）就够了。

| 推测 | 说明 |
|------|------|
| **EIS 防抖需要极高精度陀螺仪** | ICM-42688-P 的陀螺仪噪声密度仅 2.8 mdps/√Hz——是 BMI270 的 1/3 |
| **运动检测灵敏度** | 精确检测"是否在走路""是否在跑步"来触发/停止录制 |
| **姿态估计** | 判断镜头朝向，自动校正"倒挂""歪斜"等场景 |

**对我方的启示**：如果要做好 EIS（电子防抖），**不能用便宜 IMU**——ICM-42688-P 或同级（Bosch BMI323）是正确选择，虽然贵 $1-2 但画面稳定性差距巨大。

### 6.4 艾为(Awinic)三件套的选型逻辑

Looki 用了 **3 颗艾为 IC**：AW88166（PA）+ AW86225（马达驱动）+ AW21024（LED 驱动）

| 分析 | 说明 |
|------|------|
| **打包议价** | 三颗同一供应商 → 总价可能打 8 折 |
| **技术支持统一** | 一个 FAE 解决三个模块的问题 |
| **驱动兼容性** | 艾为 IC 都用 I²C 接口，驱动框架统一 |
| **国产替代策略** | 全部国产 IC，避免对 TI/Cirrus 等美系供应商依赖 |

**对我方的启示**：在 PA/马达/LED 这类"辅助功能 IC"上，选一家国产供应商打包合作是聪明的——艾为、汇顶、恒玄都是好选择。

## 7. 与我方方案对比（修正版）

| 模块 | Looki L1（拆机确认） | 我方方案 C（鹅卵石精灵） | 差异 |
|------|---------------------|------------------------|------|
| SoC | QC SW5100P ($13.5) | RV1126 ($9.5) | **-$4** 我方便宜 |
| Wi-Fi/BT | WCN3980 ($3.0) | 独立模组 W800 ($2.5) | **-$0.5** |
| 存储 | 32GB ePoP ($24) | 64GB eMMC + 1GB LPDDR4 ($30) | **+$6** 我方贵（更大容量+分立件） |
| 摄像头 | IMX681 12MP ($7.0) | IMX415 8MP ($6.5) | **-$0.5** |
| IMU | ICM-42688-P ($3.0) | BMI270 ($1.5) | **-$1.5** 但 EIS 效果差 |
| 语音 AI | GX8002 ($2.0) | 无（靠主 SoC）| **-$2** 但续航劣势 |
| 触控 | IQS7211E ($1.2) | 简单微动开关 ($0.2) | **-$1** 但交互差 |
| PA + Speaker | AW88166 + Speaker ($1.1) | 无扬声器 | **-$1.1** |
| 防水等级 | IP67 ($2.0) | IP54 ($1.0) | **-$1** |
| **总 COGS** | **$89.05** | **$68.50** | **-$20.55** |

**关键结论**：
- 我方方案比 Looki 便宜约 **$20.5/台**——主要节省来自：国产 SoC(-$4) + 无语音前端(-$2) + 无触控IC(-$1) + 无扬声器(-$1) + 便宜 IMU(-$1.5) + IP54(-$1)
- 但也牺牲了：续航（无 always-on 前端）、交互丰富度（无 trackpad/扬声器）、EIS 精度
- **如果我们也想做到 Looki 的体验水平**（12h 续航 + 触控交互 + EIS），BOM 需要加回约 $10-15 → COGS ≈ $62-67

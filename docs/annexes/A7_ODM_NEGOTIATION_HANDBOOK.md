## 1. 先搞清楚：OEM vs ODM vs JDM 到底选哪种

### 1.1 三种模式对比

| 模式 | 你做什么 | 工厂做什么 | 适合谁 | 风险 |
|---|---|---|---|---|
| **OEM（纯代工）** | 你出全部设计（ID/ME/EE/SW/BOM）| 工厂只负责贴片+组装+测试 | 你有自己的硬件团队（≥5人） | 低（你掌控一切） |
| **ODM（设计+制造）** | 你出需求+ID（可选）| 工厂出 EE+ME+部分 SW+制造 | 你没有硬件团队，想快速出货 | 中高（依赖工厂能力） |
| **JDM（联合开发）** | 你出产品定义+核心算法+ID | 工厂出硬件全栈+结构+测试 | 创业公司首选（能力互补） | 中（需要强PM管控） |

### 1.2 类 Looki 这种产品应该选什么？

**推荐：JDM 模式**——因为：
- 你的核心竞争力是 **AI 算法 + 产品定义 + 品牌**
- 硬件（EE/ME/ISP/声学）不是你的壁垒，但做不好会死
- JDM = 你出"灵魂"，工厂出"身体"，但你必须有**强技术 PM 管控全过程**

### 1.3 JDM 下的分工表

| 模块 | 你（品牌方）| ODM/JDM | 备注 |
|---|---|---|---|
| 产品定义 / PRD | ✅ | | 你的命 |
| 工业设计 ID | ✅ 或外包 | 协助落地 | 你出方案，工厂评估可制造性 |
| 结构设计 ME | | ✅ | 工厂做，你审 |
| 电子硬件 EE | | ✅ | 工厂做，你审原理图 |
| 嵌入式 BSP | | ✅ | SoC bring-up + 驱动 |
| 应用层固件 | ✅ | 配合 | 核心逻辑自己写 |
| AI 算法 | ✅ | | 你的壁垒 |
| 云端 / App | ✅ | | 你的壁垒 |
| ISP 调试 | 协助 | ✅ | 工厂做（专业） |
| 声学调试 | 协助 | ✅ | 工厂做 |
| 认证 | 协助 | ✅ | 工厂主导 |
| 模具 / 开模 | | ✅ | 费用你出 |
| 供应链 / 采购 | 核心件你指定 | ✅ | 二供策略 |
| 生产 / 组装 | 品质稽核 | ✅ | 你派人蹲 |
| 测试 | 定义标准 | ✅ 执行 | 你定义 FCT 用例 |

> ⚠️ **黄金原则**：软件/算法/数据/品牌必须 100% 自己掌控，硬件可以让工厂做，但**设计文件、源代码、模具所有权**必须明确归你。

## 2. ODM 筛选策略：从 100 家到 3 家的漏斗

### 2.1 信息源（去哪儿找 ODM）

| 渠道 | 优劣 | 操作 |
|---|---|---|
| **华强北 / 华秋 / 方案商展厅** | 数量多、鱼龙混杂 | 只做初筛，别现场签约 |
| **EEWORLD / 电子发烧友 / 与非网** | 技术论坛可看口碑 | 搜"RV1126 方案商" |
| **微信搜"穿戴方案"相关群** | 鱼龙混杂 | 验证对方公司是否真实 |
| **1688 / 阿里国际站** | 看报价做参考 | 不要在线上直接下单高精密件 |
| **CES / 环球资源展 / 电子展** | 能见到决策人 | 带你的 Demo / 渲染图去 |
| **朋友/投资人/同行引荐** | **最有效** | 找做过类似品类的创始人问 |
| **SoC 原厂 FAE 推荐** | **非常靠谱** | 瑞芯微 / Sigmastar 销售可以推荐合作方案商 |
| **认证机构推荐** | 华测/SGS 有工厂资源 | 可以问他们 |

### 2.2 漏斗筛选模型

```
第一轮：名单搜集（100 家）
   过滤条件：做过 IPC / 运动相机 / 穿戴设备 / 智能眼镜
   ↓
第二轮：初步联系（20-30 家）
   发 NDA + 基本需求文档，收报价和能力介绍
   ↓
第三轮：实地考察（5-8 家）
   现场看产线、看产能、看在做的项目、看人
   ↓
第四轮：技术深入评估（3 家）
   给详细 Spec，要方案设计 + 报价 + 排期
   ↓
第五轮：最终选择（1 家主 + 1 家备）
   签框架合同 + 先做一轮 EVT
```

### 2.3 初步联系时发什么给工厂

**必备材料包**（PDF/PPT 就行，10 页以内）：
1. **公司介绍**：1 页（团队背景、融资情况、品牌愿景）
2. **产品概要**：2 页（3D 渲染 + 功能列表 + 核心 Spec）
3. **BOM 初步选型**：1 页（主控、Sensor、电池容量）
4. **量产需求**：1 页（首批数量、时间节点、目标价格）
5. **合作模式说明**：1 页（你做什么、他做什么）
6. **NDA**：签了再发核心算法信息

> ⚠️ **坑**：不要在没签 NDA 前把你的核心创意、AI 方案、商业计划全部暴露——有些工厂会拿你的方案去找别的客户做。

### 2.4 实地考察 Checklist（到了工厂看什么）

| 看什么 | 怎么判断 | 红旗 |
|---|---|---|
| **前台/展厅** | 展柜产品品类是否相关 | 展柜全是跟你品类无关的 |
| **SMT 产线** | 看品牌（松下 / 西门子 / JUKI）、线数 | 只有 1 条老线 |
| **无尘车间** | 相机产品必须有（查等级标识） | 没有无尘间 = 不能做相机 |
| **在制品（WIP）** | 看现在在做什么项目 | 桌上堆的全是低端品 |
| **测试区** | 有没有 FCT 治具、老化柜 | 只有人工目检 |
| **仓库** | 元件管理有没有 MES 系统 | 物料散放 = 品质隐患 |
| **工程部** | 几个 EE、几个 ME、几个 SW | 只有 2-3 个工程师 |
| **样机间** | 能否看到以往项目成品 | 不让你看 = 藏着问题 |
| **管理层** | 总经理/技术总监是否出面 | 只派销售忽悠 = 不够重视 |
| **ISO/品质** | ISO9001 证书是否在有效期 | 证书过期了 = 管理松散 |

## 3. 八大维度能力评估打分卡

> **使用方法**：每个维度 10 分制打分，总分 80 分。60 分以上可以深入谈，70 分以上优秀。每个维度列出你该问什么、怎么验证、红旗信号。

---

### 维度一：硬件 EE 能力（10 分）

| 评估项 | 具体提问 | 验证方法 | 得分标准 |
|---|---|---|---|
| **SoC 经验** | "你们做过哪些 RV1126/Ambarella/Sigmastar 的项目？" | 要求看 PCB 实物 | 做过 ≥ 3 款同类 = 8 分 |
| **PCB 设计能力** | "你们 PCB 最高做过几层？HDI 做过吗？" | 看图纸 | 8 层 HDI 有经验 = 9 分 |
| **射频/天线** | "Wi-Fi/BLE 天线是用公模还是自己设计？" | 看是否有网分仪/暗室 | 有暗室 = 10 分 |
| **电源设计** | "穿戴设备的低功耗你们怎么做？" | 看 sleep 电流实测数据 | 能说出 μA 级方案 = 9 分 |
| **信号完整性** | "MIPI/USB3.0 高速走线你们怎么控制？" | 看是否用仿真工具 | 用 SI 仿真 = 9 分 |
| **EMC 经验** | "上次 EMC 测试一次通过率多少？" | 要求看报告 | 首次通过率 > 80% = 9 分 |
| **BOM 替代能力** | "如果某颗料断货你们怎么处理？" | 看二供清单 | 关键料都有二供 = 8 分 |

**问这句话试探深度**：
> "IMX415 走 MIPI 4-Lane 到 RV1126 的 ISP，时钟频率和 EQ 怎么配？你们踩过什么坑？"
> 如果对方能说出具体问题和解法 → ✅ 真做过；如果含糊 → ❌ 外行。

**红旗 🚩**：
- "原理图我们不给客户看" → 意味着 IP 不归你
- "我们用别人的公模板改一改" → 可能尺寸/功耗达不到你的需求
- 工程师只有 1-2 个 → 根本扛不住一个完整项目

---

### 维度二：软件能力（10 分）

| 评估项 | 具体提问 | 验证方法 | 得分标准 |
|---|---|---|---|
| **BSP/驱动** | "RV1126 的 Linux BSP 你们自己 porting 还是用公版？" | 看代码仓库 | 自己 porting + 定制 = 9 分 |
| **视频编解码** | "H.265 编码参数怎么调？分段录制断电保护你们怎么做？" | 看实测数据 | 有断电保护方案 = 9 分 |
| **OTA 能力** | "你们做过差分 OTA 吗？灰度发布？回滚？" | 看 OTA 系统后台 | 有完整 OTA 系统 = 9 分 |
| **低功耗唤醒** | "设备 sleep → 按键唤醒的延迟多少？" | 实测 | < 300ms = 9 分 |
| **文件系统** | "为什么选 F2FS/ext4？写穿寿命怎么控制？" | 看 wear leveling 策略 | 有明确策略 = 8 分 |
| **调试能力** | "kernel panic / hard fault 你们怎么抓？" | 看 coredump 流程 | 有完整 crash 分析链 = 9 分 |
| **API/协议** | "设备和 App 之间的通信协议是什么？" | 看文档 | 有规范协议文档 = 8 分 |

**问这句话试探深度**：
> "你们 Linux 用 Buildroot 还是 Yocto？BSP 里 ISP 驱动是 V4L2 还是私有？遇到过 iommu 的坑吗？"
> 如果对方滔滔不绝 → ✅；如果转移话题 → ❌

**红旗 🚩**：
- "软件你们自己做，我们不负责" → 可能连 BSP 都 porting 不了
- "我们用原厂 SDK 不改" → 无法定制
- "源码不提供" → 你被锁死

---

### 维度三：算法能力（10 分）

| 评估项 | 具体提问 | 验证方法 | 得分标准 |
|---|---|---|---|
| **NPU 模型部署** | "你们在 RV1126 RKNN 上跑过什么模型？" | 看 Demo 视频 | 跑过人脸检测+分类 = 8 分 |
| **模型量化** | "INT8 量化后精度掉多少？怎么补偿？" | 看对比数据 | 精度损失 < 3% = 9 分 |
| **ISP 3A 算法** | "AWB/AE/AF 你们是用原厂还是自己调？" | 看调试工具链 | 自己调 + 有色温曲线 = 9 分 |
| **EIS 防抖** | "你们的 EIS 是用 6-DoF 陀螺仪数据做 warp 的吗？" | 看步行录制对比 | 有实际效果对比视频 = 9 分 |
| **音频算法** | "降噪用什么方案？RNNoise 还是自研？风噪门怎么做的？" | 实际录音对比 | 有风噪实测数据 = 9 分 |
| **端侧 AI 推理** | "人脸模糊的推理速度？功耗增量？" | 看 profiling 数据 | 30fps 人脸检测 < 50ms = 9 分 |
| **算法交付方式** | "模型是给 .rknn 文件还是源码？" | 看交付物列表 | 提供源码 + 训练流程 = 10 分 |

**问这句话试探深度**：
> "RKNN 量化 YOLOv5 的时候 anchor-free 和 anchor-based 有什么区别？输出后处理你们在 NPU 上做还是 CPU？"

**红旗 🚩**：
- "算法我们外包给别人" → 你拿不到核心交付物
- "我们只做 Demo，量产部署你们自己来" → 交接一定出问题
- "NPU 我们没用过，都跑 CPU" → 功耗和性能都不行

### 维度四：结构 ME 能力（10 分）

| 评估项 | 具体提问 | 验证方法 | 得分标准 |
|---|---|---|---|
| **穿戴件经验** | "你们做过几款穿戴产品？体积多小？" | 看实物 | 做过 < 50mm 级 = 9 分 |
| **软件** | "用 Solidworks/Creo/NX？" | 看屏幕 | 用 NX/Creo = 专业 |
| **公差控制** | "你们小件结构公差能做到多少？" | 看图纸标注 | ±0.05mm = 9 分 |
| **装配方式** | "超声焊还是卡扣还是螺丝？" | 看以往方案 | 超声焊+灌胶 = 防水好 |
| **防水密封** | "IP54 你们怎么做的？用什么胶？" | 看密封圈 + 测试报告 | 有 IP 测试报告 = 9 分 |
| **热仿真** | "你们做过 Flow Simulation 吗？" | 看仿真报告 | 有仿真 = 8 分 |
| **DFM 评审** | "拿到 ID 后你们多久给 DFM 反馈？" | 问流程 | < 3 个工作日 = 8 分 |
| **跌落仿真** | "结构跌落仿真你们用什么？" | 看 LS-DYNA/ANSYS 报告 | 有仿真 + 实测 = 9 分 |

**问这句话试探深度**：
> "46×28×11mm 的壳体，壁厚 0.8mm，PC+ABS 注塑，出模角怎么设计？滑盖机构在这个尺寸下间隙怎么控？"
> 如果对方能讨论出模角 / 顶针位 / 分型线 → ✅

**红旗 🚩**：
- "我们不做仿真，直接开模试" → 烧钱
- "壁厚 0.8 做不了，最少 1.5" → 可能不熟悉高端注塑
- "防水我们没做过" → 这款产品做不了

### 维度五：工艺与品质（10 分）

| 评估项 | 具体提问 | 验证方法 | 得分标准 |
|---|---|---|---|
| **ISO 体系** | "你们 ISO9001 / ISO14001 / IATF16949？" | 看证书 | ISO9001 有效期内 = 基础 |
| **品质人数** | "QA/QC 多少人？" | 看组织架构 | 品质人员 ≥ 总人数 8% = 8 分 |
| **进料检验（IQC）** | "来料检验用什么标准？AQL 多少？" | 看 IQC 记录 | AQL 1.5 = 9 分 |
| **过程检验（IPQC）** | "每道工序怎么检？抽检还是全检？" | 看巡检记录 | 关键工序全检 = 9 分 |
| **出货检验（OQC）** | "OQC 抽样标准？" | 看 AQL 表 | AQL 2.5 Critical / 4.0 Major = 8 分 |
| **8D 报告** | "上一个客户投诉你们怎么闭环的？" | 看 8D | 有完整 8D = 8 分 |
| **不良追溯** | "出了批量问题能追溯到哪块板哪个工位？" | 看 MES 系统 | 有 MES 追溯 = 9 分 |
| **可靠性实验室** | "你们有自己的跌落机/恒温恒湿箱/盐雾箱吗？" | 看实验室 | 有 = 8 分 |

**致命问题**：
> "你们最近一批量产的 DPPM（每百万缺陷率）是多少？"
> 好工厂能说出数字（< 500 DPPM = 优秀）；说不出来 = 没在追踪。

**红旗 🚩**：
- 没有专职品质人员 → 100% 翻车
- "品质是工程师兼着管的" → 没有独立质量体系
- 没有 MES → 追溯不了问题
- "我们良率 99%" → 吹牛，首批做到 92% 已经很好

### 维度六：设计审美能力（10 分）

| 评估项 | 具体提问 | 验证方法 | 得分标准 |
|---|---|---|---|
| **ID 团队** | "你们有自己的 ID 设计师吗？几个？" | 看团队 | 有 ≥ 2 个全职 = 8 分 |
| **CMF 能力** | "CMF 工艺（颜色/材质/表面处理）能做什么？" | 看 CMF 样板 | 有色板 + 纹理库 = 9 分 |
| **以往作品** | "给我看你们设计最漂亮的 3 款产品" | 看实物 | 审美在线 = 8 分 |
| **ID → ME 落地** | "设计方案到可制造之间你们怎么过渡？" | 看流程 | 有 DFM 联合评审 = 8 分 |
| **合作设计经验** | "你们配合过外部 ID 公司吗？" | 看案例 | 配合过知名 ID 公司 = 9 分 |

**实际操作建议**：
> 绝大多数 ODM 的 ID 能力只能做到"不丑"，做不到"惊艳"。**建议你自己找外部 ID 设计公司出方案（如 Frog / YANG Design / 洛可可 / 木马），交给 ODM 落地**。

**红旗 🚩**：
- 展厅产品看着像"十年前的设计" → 审美能力不足
- "你发个图我们改一改就行" → 不是真做 ID
- 只会用 Rhino，不会做 Keyshot 渲染 → 配合不了品牌方审美

| **老化线** | "老化柜多少台？能放多少 DUT？" | 看 | ≥ 200 DUT = 8 分 |
| **灵活度** | "首批 1000 台能不能做？交期多久？" | 问 | 愿意做小批 = 8 分 |
| **工人稳定性** | "旺季/淡季工人流动率？" | 问 | < 15% = 8 分 |

**致命问题**：
> "你们现在同时在做几个项目？产能排到什么时候了？"
> 太满 = 你的项目会被延期；太空 = 可能产品不行客户少。

**红旗 🚩**：
- 只有 1 条 SMT 线 → 排期风险极大
- 没有无尘车间 → 做不了相机产品（灰尘进光路 = 报废）
- 没有 AA 设备 → 你的摄像头模组要外部做好再送来组装（增加成本和风险）
- "我们组装外包出去" → 品质失控

---

### 维度八：供应链管理能力（10 分）

| 评估项 | 具体提问 | 验证方法 | 得分标准 |
|---|---|---|---|
| **供应商数量** | "你们 AVL（合格供应商清单）多少家？" | 看清单 | ≥ 100 家 = 8 分 |
| **采购议价** | "Rockchip 你们年采购量多少？" | 问或看合同 | 年采 > 100K = 有议价 |
| **二供策略** | "关键料（SoC/Sensor/eMMC）有二供吗？" | 看 BOM 二供标注 | 关键料都有 = 9 分 |
| **元件库存** | "你们有备安全库存吗？备多久？" | 看仓库 | 关键料备 ≥ 2 月 = 8 分 |
| **交期管控** | "如果某颗芯片交期突然从 8 周变 20 周怎么办？" | 看应急预案 | 有应急机制 = 9 分 |
| **成本透明度** | "BOM 成本你们愿意拆开给我们看吗？" | 直接问 | Open BOM = 9 分 |
| **尾单/呆料** | "项目结束后剩余物料怎么处理？" | 看合同条款 | 双方约定清晰 = 8 分 |

**致命问题**：
> "你们的 BOM 报价里，元件加价率是多少？"
> 正常 5–15%；超过 20% 就是宰你。

**红旗 🚩**：
- "BOM 我们不拆开看" → 里面一定有猫腻
- "二供？不需要，我们关系硬" → 一断货全崩
- "库存我们不备，下了单再买" → 你的排期无法保障

## 4. 深圳硬件圈 50 大潜规则坑（逐条拆解）

> 以下每条都是真金白银的教训，很多是创始人亏了几十万甚至几百万才学到的。

### 一、报价陷阱（1-10）

| # | 潜规则 | 你会怎么被坑 | 怎么防 |
|---|---|---|---|
| 1 | **NRE 报价含水分 50%+** | 工厂报 NRE（非经常性工程费）¥80 万，实际成本 ¥40 万 | 拆分到每一项（PCB 打样 / SMT / 模具 / 测试）单独询价，和市场价对比 |
| 2 | **BOM 元件加价暗扣** | 工厂从元件商拿到 ¥5 的芯片，报给你 ¥8 | 要求 **Open BOM**（BOM 公开），你有权指定供应商或自购关键料 |
| 3 | **模具费报低、制造费报高** | 模具报 ¥15 万（低于市场），但每台制造费多收 ¥10 以长期赚回来 | 把模具费和制造费**分开合同签**，单独核价 |
| 4 | **"免费设计"的代价** | 号称免设计费，但你没有设计文件所有权，换厂就要从头来 | **合同里写死所有设计文件（原理图/PCB/结构3D/BOM）归品牌方所有** |
| 5 | **样品费 vs 量产价差距** | 样品阶段报 ¥800/台让你满意，量产时变 ¥1200 说"料涨了" | 签合同时约定量产价锁定机制（汇率/材料浮动 ±5% 以内不调价） |
| 6 | **"杂费"暗坑** | 交付时额外收"测试费""包装费""仓储费""加急费" | 合同附件明确列出所有费用项，写"除列明项外无其他费用" |
| 7 | **改版收费黑洞** | "这次 PCB 改版要重新收 NRE ¥5 万" | 合同约定 EVT/DVT 阶段各包含 N 次改版，超出按实际成本 +10% |
| 8 | **MOQ（最低起订量）捆绑** | "首批必须下 5000 台，我们才接" | 谈判时坚持首批 500–1000 台试产权，PVT 后再放量 |
| 9 | **付款节奏不利** | 工厂要求"5-3-2"（开工50%/出货30%/尾款20%），你的钱全在工厂 | 坚持"3-3-3-1"（签约30%/T0 30%/出货30%/质保到期10%） |
| 10 | **汇率/材料涨价条款** | 合同里留了"材料涨价超过 X% 可调价"，然后一涨就调 | 上限锁死（年涨幅 > 15% 才触发），且只针对占 BOM > 10% 的物料 |

### 二、知识产权陷阱（11-20）

| # | 潜规则 | 你会怎么被坑 | 怎么防 |
|---|---|---|---|
| 11 | **设计文件不给你** | "原理图是我们的 know-how，不提供" | 合同第一条写：所有设计输出物（Schematic/PCB Gerber/3D/BOM/源码）所有权归甲方 |
| 12 | **模具所有权不清** | 你付了模具费，但模具"放在工厂保管"，你想换厂拿不走 | 合同写死"模具所有权归甲方，甲方有权随时要求移模" |
| 13 | **软件源码不交付** | "我们交付 .bin 固件就行了" | 合同约定交付全部源码 + 编译环境 + 文档，**定期 code escrow** |
| 14 | **工厂用你的方案接别的客户** | 你的创意变成工厂的"公模方案"卖给竞争对手 | NDA + **竞业条款**（同品类 2 年内不得为其他品牌做） |
| 15 | **专利归属不清** | 开发过程中产生的专利工厂也要分一杯 | 合同写明：项目中产生的所有 IP 归品牌方独有 |
| 16 | **工厂工程师离职带走方案** | 核心工程师跳槽去竞品，把你的方案也带走了 | 要求工厂对核心人员有竞业协议；同时你自己也留一份完整文档 |
| 17 | **模具修改后变成"新模具"** | 工厂说"修模等于重做"，再收你一遍钱 | 合同约定修模 ≤ 3 次包含在模具费中 |
| 18 | **2D/3D 图纸用工厂的模板** | 图纸上标着工厂的 logo 和图号 | 要求所有图纸用你们的模板、图号系统 |
| 19 | **测试数据不归档** | 工厂做完测试不给你原始数据 | 合同约定所有测试报告原始数据在出货后 30 天内交付 |
| 20 | **固件加密密钥工厂持有** | OTA 签名密钥在工厂那边 | **密钥管理权 100% 在你**——工厂只有烧录证书，无私钥 |

### 三、品质/良率陷阱（21-30）

| # | 潜规则 | 你会怎么被坑 | 怎么防 |
|---|---|---|---|
| 21 | **良率"达标"的定义模糊** | 工厂说良率 95%，但不算"外观不良" | 合同定义清楚：良率 = 全检合格数 / 总投入数，包含外观/功能/可靠性全部 |
| 22 | **首批良率低但不告诉你** | 工厂首批良率 70%，补投 30% 的物料费转嫁给你 | 约定：良率 < 90% 时损耗由工厂承担 |
| 23 | **"全检"变成"抽检"** | 合同写全检，实际只抽 20% | 派驻 QA 或定期突击检查 |
| 24 | **测试治具不更新** | 治具设计于 EVT 阶段，但量产时固件更新了，治具没跟上 | 要求治具同步更新，且治具所有权归你 |
| 25 | **不良品处理不透明** | 不良品被工厂"翻修"后混入良品出货 | 约定：不良品隔离 + 只能报废或降级处理（你来决定），翻修需重新全检 |
| 26 | **老化时间偷工减料** | 约定 72h 老化，实际只做 24h | 老化柜加电子锁/时间记录仪，品质人员抽查 |
| 27 | **出货前改 AQL** | 原定 AQL 2.5，出货紧急时工厂偷偷改成 6.5 | AQL 标准写进合同且不可变更 |
| 28 | **可靠性测试外包不告诉你** | 工厂号称有实验室，实际外包给不靠谱的小机构 | 指定认可的第三方（华测/SGS/TÜV/BV） |
| 29 | **退货品拆解后元件回用** | 退回来的产品，工厂把好元件拆下来用在新产品上 | 退货品只能整机报废或你收回 |
| 30 | **包装抽检不足** | 出货 10 万台，包装抽 5 台就放行 | 按 GB/T 2828.1 标准抽样，且包装跌落测试每批必做 |

### 四、排期/交付陷阱（31-40）

| # | 潜规则 | 你会怎么被坑 | 怎么防 |
|---|---|---|---|
| 31 | **排期总是"再等 2 周"** | 承诺 8 周交付，实际 14 周 | 合同约定 milestone 节点 + 逾期罚则（每延1天罚总价0.5%，上限10%） |
| 32 | **旺季挤掉你的产能** | 大客户（华为/小米/大疆）下紧急单，你被"让路" | 合同约定你的产线排期不受第三方影响；或约定专用线 |
| 33 | **T0 试模没你什么事** | 工厂试模了你不知道，等你知道已经 T2 了 | 约定每次试模**必须通知品牌方到场验收** |
| 34 | **缺料不提前告知** | SoC 交期从 8 周变 20 周，工厂不主动说 | 要求每周物料状态报告；关键料你自己下 PO（采购订单） |
| 35 | **工厂内部项目优先级低** | 你的小单（1k 台）永远排在大单后面 | 在合同里约定"项目经理 + 工程师指定"，且你有权 escalate 到总经理 |
| 36 | **"设计冻结"后还改来改去** | 工厂没告诉你冻结意味着什么，你改了一下，排期 +4 周 | 双方书面确认 freeze 时间点，freeze 后改设计需走 ECN（工程变更通知）流程 |
| 37 | **认证排期没算进总排期** | 工厂排期只算到出货，但认证还要 1-2 个月 | 总排期必须包含认证前置时间（DVT 阶段就送测） |
| 38 | **春节前赶工品质暴跌** | 春节前最后 2 周疯狂加班赶产，良率跌 10–20% | 别让交期卡在春节前 2 周，或加强 QC 频次 |
| 39 | **停工损失由谁承担** | 因你方原因（软件没做好）停线，工厂收"停线费" | 合同约定停线费标准（通常 ¥1–5 万/天），且双方责任划分清楚 |
| 40 | **"部分出货"陷阱** | 约定 5000 台 30 天交付，工厂先发 2000 台给你验收签字，剩下的遥遥无期 | 出货以"全部交付"为验收节点，部分出货不触发尾款 |

### 五、合作关系陷阱（41-50）

| # | 潜规则 | 你会怎么被坑 | 怎么防 |
|---|---|---|---|
| 41 | **销售和工程不是一批人** | 销售答应的，工程师说做不到 | 所有技术承诺必须工程师到场确认并书面签字 |
| 42 | **"大客户待遇"只是嘴上说** | 签了合同后发现你只是他们的 C 类客户 | 了解对方现有客户规模和你的占比，< 10% = 你的话语权很低 |
| 43 | **中途换工程师** | 项目做到一半核心工程师被调走或离职 | 合同约定核心人员变更需提前 30 天通知并交接 |
| 44 | **"我们很忙，你等着"** | 你发消息工厂回复延迟 3-5 天 | 约定响应 SLA（工作日 24h 内回复），project kickoff 后建立每周例会 |
| 45 | **隐瞒真实产能** | 工厂接了超过产能 200% 的单 | 考察时算：产线数 × 节拍 × 工时 = 理论最大产能 |
| 46 | **"兄弟价"没合同** | 前期关系好什么都口头说，后来翻脸无凭 | **任何承诺必须书面**（邮件/合同附件/会议纪要签字） |
| 47 | **工厂被收购或倒闭** | 小工厂现金流紧张，做着做着跑路 | 选择经营 > 5 年、员工 > 200 人的工厂；或要求银行履约保函 |
| 48 | **"这个我们也能做"** | 工厂为了接单什么都说能做，接了再说 | 每项能力都要求看**实际完成的案例**，不是 PPT |
| 49 | **保密信息泄露给竞品** | 你的产品还没上市，竞品已经出了类似的 | NDA 签罚则（违约金 = 项目总金额 × 3 倍），且限制对接人范围 |
| 50 | **合作结束后"卡模具"** | 你想换厂，工厂以"模具保管费""尾款未结"等理由不放模具 | 合同约定模具移交条件、时间（收到移模通知 15 天内交付），且押金覆盖 |

## 5. 谈判前准备：你手里应该有什么筹码

### 5.1 你的弱势（诚实面对）

作为非硬件背景创始人，工厂第一眼看你就能判断：
- ❌ 你不懂硬件 → 他们可以报高价
- ❌ 首批量小（1-5k）→ 你的优先级低
- ❌ 没有历史合作 → 无信任基础
- ❌ 公司刚成立 → 工厂怕你"做不成跑了"

### 5.2 你的筹码（主动构建）

| 筹码 | 怎么构建 | 效果 |
|---|---|---|
| **融资背景** | 拿到 TS 就可以提（即使还没打款）| 证明你有钱、有决心 |
| **品牌 / 营销能力** | 给工厂看你的小红书/抖音/海外预订数 | 工厂喜欢"能卖出去"的客户 |
| **技术专家顾问** | 花 ¥5k–2 万/月请一个**退休硬件总监**当顾问 | 谈技术时不被忽悠 |
| **SoC 原厂关系** | 先去拜访瑞芯微/Sigmastar 的深圳办公室 | 原厂推荐 = 工厂会重视 |
| **清晰的 PRD + Spec** | 就是你手上这份文档 | 工厂看到专业的文档会认真对待 |
| **首批量承诺** | 即使首批 1k，也可以说"年计划 50k" | 画饼要有根据（给出月度放量计划） |
| **付款爽快度** | 愿意预付 30% → 工厂优先排你 | 但要合同保障！ |
| **竞争报价** | "我在同时和 3 家谈" | 工厂怕丢单，会更用心 |
| **媒体/公众曝光** | "我们是媒体/KOL 推荐过来的" | 工厂看重品牌客户（可以做案例宣传） |

### 5.3 必须带去谈判桌的材料

```
✅ 公司营业执照 + 合作授权书
✅ PRD + Spec（本文档）
✅ 3D 渲染图 / ID 定稿
✅ 目标 BOM 清单（你自己初步选型）
✅ 量产计划（首批 + 12 个月放量表）
✅ 竞品实物（买一台 Insta360 GO / Plaud 当参照物）
✅ NDA 模板（你准备好的）
✅ 预算范围（BOM 目标价 + NRE 上限）
✅ 你的技术顾问（哪怕远程在线）
```

### 5.4 建议请一个"硬件技术顾问"

这是**非硬件创始人的最强武器**——找一个做过 10 年以上消费电子的人，兼职即可：

| 来源 | 费用 | 方式 |
|---|---|---|
| 前华为/大疆/小米/OPPO 硬件总监 | ¥2–5 万/月 | 兼职顾问 |
| 猪八戒/在行/行家 | ¥800–3000/小时 | 按次咨询 |
| 行业微信群/LinkedIn | 免费–¥500 | 吃饭聊天 |
| 瑞芯微/Ambarella 的 FAE | 免费 | 售前支持（但有立场） |

**顾问的价值**：
- 帮你看 BOM 报价是否合理
- 帮你审原理图
- 帮你在工厂评估时问对问题
- 帮你做 EVT/DVT 评审
- 帮你砍价（¥10 万的顾问费可能帮你省 ¥50-100 万的坑）

## 6. 合同关键条款模板与陷阱

### 6.1 合同结构建议

一份完整的 ODM/JDM 合作合同应该包含：

```
框架合同（总协议）
├─ 附件一：产品规格书（Spec）
├─ 附件二：BOM 清单 + 单价
├─ 附件三：NRE 费用明细
├─ 附件四：模具费用明细
├─ 附件五：交付物清单（含 IP 交付）
├─ 附件六：付款时间表
├─ 附件七：品质标准（AQL/良率/可靠性）
├─ 附件八：项目排期（甘特图）
├─ 附件九：NDA（保密协议）
└─ 附件十：变更管理流程（ECN）
```

### 6.2 必须死守的 20 个条款

| # | 条款 | 正确表述 | 常见陷阱 |
|---|---|---|---|
| 1 | **IP 归属** | "所有设计输出物（含原理图、PCB Gerber、3D 模型、BOM、源码、测试治具）知识产权归甲方所有" | 没写 = 默认工厂的 |
| 2 | **模具所有权** | "模具费由甲方支付，所有权归甲方，甲方有权随时移模" | "归工厂保管" ≠ 归你 |
| 3 | **源码交付** | "所有嵌入式固件源码 + 编译工具链 + 文档在每阶段结束时交付至甲方 Git 仓库" | "交付 .bin" = 锁死 |
| 4 | **BOM Open** | "BOM 采购价向甲方公开，甲方有权指定供应商或自购" | "总包价" = 黑箱 |
| 5 | **价格锁定** | "量产单价 ¥X 在首 12 个月内不变，超过 12 个月双方协商" | "随市场波动调整" = 没锁 |
| 6 | **付款节奏** | "30%（签约）- 30%（EVT验收）- 30%（出货验收）- 10%（质保期满）" | "50%-50%" = 无约束 |
| 7 | **验收标准** | "良率 ≥ 92%，AQL Critical 0 / Major 2.5 / Minor 4.0" | 没定义 = 各说各话 |
| 8 | **逾期罚则** | "乙方逾期交付超过 7 天，每逾期 1 天罚合同总额 0.3%，上限 10%" | 没罚则 = 没压力 |
| 9 | **品质赔偿** | "因乙方品质问题导致批量退货/召回，乙方承担全部直接损失" | "最多赔本批次合同额" = 不够 |
| 10 | **竞业限制** | "乙方在合作期间及终止后 24 个月内，不得为同品类竞品提供服务" | 没竞业 = 你的方案泄露 |
| 11 | **保密罚则** | "违反 NDA 违约金为合同总额的 300%" | "承担损失" 难举证 |
| 12 | **变更管理** | "任何设计变更需走书面 ECN 流程，双方签字生效" | 口头改 = 后面扯皮 |
| 13 | **停线责任** | "因甲方原因停线，甲方按 ¥X/天补偿；因乙方原因停线，乙方承担" | 不分责 = 全赖你 |
| 14 | **退出机制** | "甲方提前 60 天书面通知可终止合同，支付已完成工作量费用" | "乙方不同意不能终止" = 被绑架 |
| 15 | **认证义务** | "乙方负责 CCC/FCC/CE 认证，费用由甲方承担，不通过乙方重做至通过" | "认证不过你自己负责" |
| 16 | **质保期** | "产品出货后 12 个月内非人为品质问题由乙方免费维修/换新" | 没质保 = 出货就不管了 |
| 17 | **尾款条件** | "10% 尾款在质保期（12 个月）满且退货率 < 5% 后支付" | 尾款无条件支付 = 没约束 |
| 18 | **审计权** | "甲方有权不定期派人进入乙方产线审计生产过程" | "不允许参观" = 黑箱 |
| 19 | **物料残余** | "项目终止时，已采购未使用物料由甲方按成本价回购，呆滞 > 180 天乙方自行消化" | "物料全部你买" = 风险全在你 |
| 20 | **管辖/仲裁** | "争议由深圳国际仲裁院仲裁" | 去对方所在地法院 = 主场优势 |

### 6.3 分阶段合同建议

> **不要一次签全套！**——先签 NRE 合同（EVT/DVT），验证工厂能力后再签量产合同。

```
第一阶段合同：NRE + EVT（风险有限，¥20-50万）
   → 验收通过后 →
第二阶段合同：DVT + 模具开发（¥50-150万）
   → 验收通过后 →
第三阶段合同：PVT + 量产（金额按批次签）
```

这样即使第一阶段发现工厂不行，你的损失控制在 ¥20-50 万以内，不至于全军覆没。

## 7. 沟通话术：每一轮怎么说

### 7.1 第一次联系（微信/电话/邮件）

**错误示范** ❌：
> "你好，我想做一款 AI 相机，类似 Humane Pin 那种，你们能做吗？预算大概 100 万。"
> → 暴露了你不懂行 + 预算底牌，工厂会按 100 万来报。

**正确示范** ✅：
> "X 总您好，我们是 [品牌名]，已完成产品定义和工业设计。我们正在评估 3-5 家合作伙伴做穿戴式 AI 相机的 JDM 合作。产品基于 RV1126 + IMX415，首批 2k-5k 台，年计划 5 万台。请问贵司是否有相关产品经验？方便安排一次技术沟通吗？附件是我们的产品概要（已签 NDA 后发详细 Spec）。"

**话术解析**：
- ✅ 提到具体 SoC/Sensor → 证明你做过功课
- ✅ "3-5 家评估" → 制造竞争压力
- ✅ "首批 2k-5k + 年计划 5 万" → 让工厂觉得有量
- ✅ "NDA 后发详细" → 显示专业和保密意识

### 7.2 首次技术沟通（30 分钟会议）

**你要问的 8 个问题**（按顺序）：

1. "你们最近做过最像我们这个的产品是哪款？能看看实物吗？"
2. "如果基于 RV1126 + IMX415 做，有没有现成的参考设计？"
3. "ISP 调试你们是自己做还是找原厂支持？"
4. "850mAh 电池持续录制 4 小时，你们初步评估可行性如何？"
5. "首批 2000 台的 NRE + 模具费大致什么范围？"
6. "从签合同到 EVT 样机出来大概多久？"
7. "你们现在产能排到什么时候了？有空余产线吗？"
8. "合作模式上，设计文件和源码的交付方式是什么？"

**观察对方怎么回答**：
- 如果说"没问题，都能做" → ⚠️ 可能在忽悠
- 如果说"这个有难度，我们建议 XX 方案替代" → ✅ 诚实
- 如果追着问你技术细节 → ✅ 工程师认真
- 如果只谈钱不谈技术 → ⚠️ 销售导向

### 7.3 报价还价话术

**工厂报价 ¥80 万 NRE 时**：

> "谢谢报价。我看了一下，PCB 打样 + SMT 小批量市场价大约 ¥X，模具按这个尺寸大概 ¥Y，软件 BSP porting 我了解行情是 ¥Z。总体看这个报价和我们预期有差距。我们同时在评估 [另一家名字] 的方案，他们报价在 ¥50-55 万区间。贵司是否有优化空间？我们可以在 NRE 阶段给到 50% 预付来保障贵司。"

**话术解析**：
- ✅ 拆分报价 → 证明你做了功课
- ✅ 引入竞争 → 制造价格压力
- ✅ 给出对价（快速预付）→ 让工厂有台阶下

### 7.4 砍价的合理空间

| 费用项 | 工厂首次报价的水分 | 合理砍幅 |
|---|---|---|
| NRE 工程费 | 30–50% | 砍 20–30% |
| 模具费 | 10–30% | 砍 10–20%（除非你懂模具） |
| BOM 元件 | 10–25% | 要求 Open BOM + 自购关键料 |
| 制造费 | 20–40% | 砍 15–25% |
| 测试费 | 50%+ | 必须拆细看，很多项目是免费 |

### 7.5 当工厂说"做不到"时的应对

| 工厂说 | 真实含义 | 你的应对 |
|---|---|---|
| "这个需求太难做" | 可能真的难 / 可能想加价 | "那如果放宽到 XX 程度呢？技术上主要难在哪？" |
| "首批必须 5000 台" | 想要更大的单 | "我们可以签 LOI 承诺年度 3 万台，但首批就按 2000 来" |
| "排期最快 6 个月" | 产能紧张 / 优先级低 | "如果 NRE 加急费用我们可以承担一部分呢？" |
| "这个价做不了" | 利润不够 / 确实很难 | "哪一项拉高了成本？我们看能不能调整 Spec" |
| "设计文件不能给" | 这是他们的核心保护 | "这是我们的底线条件，写进合同可以谈付出方式" |

### 7.6 每周例会模板

项目启动后，建议每周固定 30 分钟例会：

```
议程（每周一 10:00，腾讯会议）：
1. [5min] 上周 Action 回顾
2. [10min] 各模块进展（EE/ME/SW/采购）
3. [5min] 风险/问题升级
4. [5min] 本周 Action + Owner
5. [5min] 其他

会议纪要模板：
- 日期/参会人
- 进展更新（逐项）
- 问题&风险清单
- Action Item 表（内容/Owner/Deadline）
- 下次会议时间
→ 会后 2h 内发邮件确认，双方签字归档
```

## 10. 创始人自保原则 20 条

> 这 20 条是血和泪换来的——每一条背后都有一家倒闭的公司。

### IP 保护篇

| # | 原则 | 执行方式 |
|---|---|---|
| 1 | **核心算法永远不给工厂** | AI 模型以 .rknn 加密文件交付，训练代码不出手 |
| 2 | **固件签名密钥你来管** | 用 HSM（硬件安全模块）管理私钥，工厂只有公钥 |
| 3 | **所有文件日期水印** | 每份发给工厂的文件加水印"[公司名] Confidential - [日期]" |
| 4 | **设计文件分批交付** | EVT 只给必要的，DVT 再给全套——防止还没合作深入就被复制 |
| 5 | **定期做 Code Escrow** | 每月把工厂交付的源码存到第三方（如 Iron Mountain / 公证处） |

### 资金安全篇

| # | 原则 | 执行方式 |
|---|---|---|
| 6 | **永远不一次付完** | 分 4-5 个节点付款，每个节点有明确验收条件 |
| 7 | **尾款绑质保** | 10% 尾款等质保期满才付 |
| 8 | **设立项目专户** | 项目资金和公司运营资金分开 |
| 9 | **小额开始试** | 第一阶段合同控制在 ¥30-50 万以内验证工厂 |
| 10 | **永远保留 Plan B** | 随时有能力换厂（IP 在手 + 文件齐全 + 模具可移） |

### 过程管控篇

| # | 原则 | 执行方式 |
|---|---|---|
| 11 | **每周例会雷打不动** | 哪怕没进展也要开——停止沟通 = 项目失控 |
| 12 | **关键节点必须到场** | T0 试模、EVT 验收、PVT 首件——你人必须在工厂 |
| 13 | **所有承诺书面化** | 微信聊天不算，要邮件 + 会议纪要签字 |
| 14 | **Bug 分优先级管理** | P0（阻塞）/ P1（严重）/ P2（一般）/ P3（优化），P0 24h 响应 |
| 15 | **定期 Review BOM 成本** | 每季度和工厂一起做 Cost Review，防止被慢慢加价 |

### 心态篇

| # | 原则 | 说明 |
|---|---|---|
| 16 | **不要怕丢面子问"笨问题"** | 你越装懂，工厂越好忽悠你 |
| 17 | **不要被"关系"绑架** | 再好的交情也要白纸黑字 |

| 19 | **不要赶工** | 赶出来的东西一定有问题——宁可延期 1 个月也别牺牲品质 |
| 20 | **不要All-in一家** | 永远同时接触 2-3 家工厂，保持自己的选择权 |

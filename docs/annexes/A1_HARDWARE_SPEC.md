## 2. 主控 SoC

| 项目 | 规格 |
|---|---|
| 型号 | Rockchip RV1126 |
| 制程 | 14nm |
| CPU | Quad-core ARM Cortex-A7 @ 1.5 GHz |
| NPU | 2.0 TOPS @ INT8 (RKNN) |
| ISP | 4K@30fps，支持 HDR、3-DNR、Wide Dynamic Range |
| 视频编码 | H.264 / H.265 编解码，最高 4K@30fps |
| 内存接口 | LPDDR3/4 / DDR3L 32-bit |
| 存储接口 | eMMC 5.1 / SDIO 3.0 |
| 包装 | LFBGA 14×14 |
| 备用方案 | Sigmastar SSC8836（成本敏感版） / Ambarella H22（高端版） |

**选型理由**：
- ✅ NPU 2 TOPS 足够跑端侧人脸模糊 + VAD + 场景分类
- ✅ ISP 内置 HDR / WDR，户外强光场景表现好
- ✅ 国产生态完善，资料丰富，方案商多
- ✅ 单价 $8–12，性价比高

## 7. 电池与充电

| 项目 | 规格 |
|---|---|
| 电芯类型 | 锂聚合物（LiPo） |
| 容量 | 850 mAh / 3.85V / 3.27 Wh |

| 续航场景 | |
| - 持续录制（1080p@30fps） | ≥ 4h |
| - 间歇使用（每小时 30s × 5 次） | ≥ 12h |
| - 待机（戴着不录） | ≥ 24h |
| - 休眠（充电盒中） | ≥ 7 天 |

- 电池外壳温度 ≤ 50°C

- SoC 结温 ≤ 90°C

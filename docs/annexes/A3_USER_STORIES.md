## Epic 1：开箱与配网 (Out-of-Box Experience)

### US-1.1 首次配网

| 字段 | 内容 |
|---|---|
| **角色** | 新用户（刚拆开包装） |
| **故事** | 作为一个刚拿到 Lumi 的用户，我希望在 5 分钟内完成设备配网和账号绑定，以便尽快开始使用 |
| **优先级** | P0 |
| **故事点** | 8 |

**验收准则**：
- **Given** 用户首次长按电源键开机
- **When** 打开 Lumi App 并点击"添加设备"
- **Then** App 通过 BLE 发现设备（≤ 10s）→ 用户选择 Wi-Fi 并输入密码 → 配网成功（总耗时 ≤ 90s）→ 跳转账号绑定 → 完成隐私引导 → 进入主页

**边界条件**：
- Wi-Fi 仅支持 2.4GHz 时需明确提示
- 密码错误时给出具体错误（而非泛泛"连接失败"）
- 断网重试 ≤ 3 次自动放弃并给出诊断建议

---

### US-1.2 非技术用户配网

| 字段 | 内容 |
|---|---|
| **角色** | 50 岁以上非技术用户（如 Marcus 的父母） |
| **故事** | 作为一个不熟悉智能设备的用户，我希望配网过程有清晰的图文引导，以便我不需要求助他人即可完成设置 |
| **优先级** | P0 |
| **故事点** | 5 |

**验收准则**：
- **Given** 用户打开 App
- **When** 进入配网流程
- **Then** 每一步都有动画示意 + 大字体说明；无需手动输入设备 ID（自动发现）；失败时有"一键求助"（分享链接给家人远程指导）

---

### US-1.3 配网失败诊断

| 字段 | 内容 |
|---|---|
| **角色** | 任何用户 |
| **故事** | 当配网失败时，我希望看到明确的原因和解决方案，而不是只看到"连接失败" |
| **优先级** | P0 |
| **故事点** | 5 |

**验收准则**：
- **Given** 配网 3 次失败
- **When** 系统自动进入诊断模式
- **Then** 显示可能原因列表（Wi-Fi 频段不对 / 密码错误 / 路由器距离太远 / 设备固件需更新）+ 每条原因的解决操作

## Epic 2：被动捕捉 (Capture)

### US-2.1 单击录制高光片段

| 字段 | 内容 |
|---|---|
| **角色** | Vivian（内容创作者） |
| **故事** | 作为一个 Vlogger，我希望单击按键就能录制一段 30 秒的高光视频，以便在不打断生活的情况下捕捉有趣的瞬间 |
| **优先级** | P0 |
| **故事点** | 5 |

**验收准则**：
- **Given** 设备处于待机/佩戴状态
- **When** 用户单击主按键
- **Then** 设备 ≤ 500ms 内开始录制 → 红灯亮起 → 录制 30s 后自动停止 → 文件保存 → 轻震反馈

**边界条件**：
- 存储满时单击提示"存储已满"（LED 闪红 3 次）
- 电量 < 5% 时提示"电量不足"

---

|---|---|
| **角色** | Alex（户外爱好者） |
| **故事** | 作为一个骑行爱好者，我希望双击后设备持续录制直到我再次双击，以便完整记录一段骑行 |
| **优先级** | P0 |
| **故事点** | 5 |

**验收准则**：
- **Given** 设备待机
- **When** 用户双击主按键
- **Then** 开始连续录制 → 红灯常亮 → 每 5 分钟自动分段 → 再次双击停止 → 保存所有分段

---

### US-2.3 长按取消最近录制

| 字段 | 内容 |
|---|---|
| **角色** | 任何用户 |
| **故事** | 作为一个注重隐私的用户，如果我不小心录到了不该录的东西，我希望长按按键就能删除最近 30 秒的录制 |
| **优先级** | P0 |
| **故事点** | 3 |

**验收准则**：
- **Given** 设备正在录制或刚录完
- **When** 用户长按主按键 3 秒
- **Then** 停止录制 + 删除最近一段 → 三次短震确认 → LED 闪白 2 次

---

### US-2.4 录制状态明确告知

|---|---|

| **故事点** | 3 |

**验收准则**：
- **Given** 设备正在录制
- **When** 任何人从正面/侧面观察设备
- **Then** 红色 LED 明显可见（亮度自动调节，暗环境不刺眼但可见）+ 可选提示音（嘀一声）



---

### US-2.5 场景自动触发录制

| 字段 | 内容 |
|---|---|

## Epic 6：隐私控制 (Privacy)

### US-6.1 物理静音键

| 字段 | 内容 |
|---|---|
| **角色** | 所有用户 |
| **故事** | 作为用户，在会议/医院/私密场合，我希望一键物理关闭所有传感器，以确保 100% 不录制 |

### US-8.3 故障自动报告

| 字段 | 内容 |
|---|---|
| **角色** | 所有用户 |
| **故事** | 作为用户，如果设备遇到故障（死机/录制失败/过热），我希望它能自动上报日志，以便售后团队主动联系我 |
| **优先级** | P0 |
| **故事点** | 8 |

**验收准则**：
- **Given** 设备发生异常（crash/过热保护/录制中断）
- **When** 设备恢复正常或下次连接网络
- **Then** 自动上传诊断日志（匿名化） → App 显示"设备曾遇到问题，已自动报告" → 用户可选择提交/忽略

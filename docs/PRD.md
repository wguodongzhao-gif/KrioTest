## 1. 产品概述

### 1.1 一句话定义

> **Lumi 是一款 35g 重的磁吸穿戴式 AI 相机，能够自动捕捉你日常的高光时刻，由多模态 AI 自动生成 Vlog 短片与可问答的"个人记忆库"。**

### 1.2 产品愿景

让"记录生活"这件事的成本归零——用户不需要拿出手机、不需要构图、不需要剪辑，只需要"活在当下"，AI 完成剩下的事。

### 1.3 产品使命

| 用户痛点 | Lumi 的回答 |
|---|---|
| Vlog 拍摄打断生活节奏 | **被动捕捉**，戴上即记录 |
| 视频堆积无法整理 | **AI 自动剪辑**，每天 1 条 Vlog |
| 记忆碎片化、检索困难 | **多模态 RAG**，用自然语言"问"自己的过去 |
| 隐私担忧 | **隐私优先设计**，物理 + 软件 + 政策三重保障 |

### 1.4 商业模式

```
硬件销售 (一次性)
   定价：¥1,999  |  BOM: ¥600  |  毛利率：~50%
            +
订阅服务 (Lumi+)
   定价：¥39/月 或 ¥299/年
   - 无限云端存储
   - 高级 AI 功能（多模态问答、深度剪辑、跨设备记忆同步）
   - 早期访问新模型
            +
内容生态 (后续)
   - 配饰商店（替换磁吸件、挂绳、保护壳）
   - 情景包（不同剪辑风格、配乐）
```

预期 LTV: ¥1,999 + ¥299 × 2.5 年 ≈ **¥2,750/用户**

### 1.5 核心假设 (Hypotheses)

| # | 假设 | 验证方式 | 验证阶段 |
|---|---|---|---|
| H1 | 用户愿意为"全自动 Vlog"支付 ¥1,999 | 假产品页面预订 CPI < ¥150 | Phase 0 |
| H2 | 4 小时持续录制可在 35g 重量内实现 | EVT 工程样机热/续航测试 | Phase 2 |
| H3 | 端侧 + 云端 AI 单用户日成本 < ¥3 | POC 成本模型实测 | Phase 1 |
| H4 | 用户对"穿戴式录制"隐私担忧可被产品设计化解 | 100 人盲测，购买意愿 ≥ 30% | Phase 0 |
| H5 | AI 自动剪辑的 Vlog 用户满意度 ≥ 7/10 | Beta 用户 NPS 测试 | Phase 4 |

## 3. 用户画像

### 3.1 Primary Persona — Vlogger Vivian

```
姓名:        Vivian, 28岁, 上海, 内容创作者 / 自媒体
收入:        ¥15–30K/月
设备:        iPhone 15 Pro, MacBook Air, 大疆 Pocket 3
使用频率:    每天 4–8 小时穿戴

核心目标:
  - 每天产出 1–3 条短视频维持账号活跃
  - 不被拍摄打断生活和创作灵感

痛点 (JTBD):
  - 拿手机拍 Vlog 太刻意，画面僵硬
  - 剪辑 1 条 Vlog 平均 2 小时，挤占创作时间
  - 灵光一现的瞬间错过了就没了

成功标准 (定义"她爱上 Lumi"):
  - 每日上传 Vlog 数量提升 100%
  - 单条剪辑时间从 2h → 5min
```

### 3.2 Secondary Persona — Memory Marcus

```
姓名:        Marcus, 38岁, 北京, 高管 / 父亲
收入:        ¥80K+/月
设备:        iPhone, 华为手表, AirPods Pro

核心目标:
  - 留住孩子成长的细节
  - 工作中的创意/对话能可检索

痛点:
  - 记忆衰退（30+ 普遍）
  - 想找 3 个月前的某次对话内容找不到
  - 与家人聚会忙着拍照反而错过当下

成功标准:
  - 每月主动用 Lumi 检索记忆 ≥ 5 次
  - 自动生成的"家庭月度回顾"成为传家级内容
```

### 3.3 Tertiary Persona — Adventure Alex

```
姓名:        Alex, 24岁, 成都, 户外爱好者
收入:        ¥10K/月
设备:        iPhone, GoPro Hero 12, 无人机

核心目标:
  - 户外活动（骑行、徒步、滑雪）记录
  - 不想戴 GoPro 那么醒目

痛点:
  - GoPro 太重、太显眼
  - 启停操作打断节奏
  - 后期剪辑工程量大

成功标准:
  - Lumi 替代 80% 的 GoPro 使用场景
  - "回家就有 Vlog 看"
```

### 3.4 Anti-Persona（不要为他们设计）

- **隐私零容忍党**：任何相机都拒绝
- **专业摄影师**：只接受 4K HDR Log，Lumi 画质不够
- **极端运动**：需要 IP68 + 防暴击，Lumi 不适合

## 4. 用户故事 Epic 总览

> 完整 INVEST 格式与验收准则见 [附录 A3](annexes/A3_USER_STORIES.md)

### Epic 1：开箱与配网（Out-of-Box Experience）
- US-1.1 5 分钟内完成配网
- US-1.2 不会编程的人也能成功使用
- US-1.3 失败时自动诊断给出引导

### Epic 2：被动捕捉（Capture）
- US-2.1 单击触发录制 30s 高光片段
- US-2.2 自动场景检测触发录制
- US-2.3 长按结束 / 取消最近一段
- US-2.4 红灯/提示音明确告知正在录制

### Epic 3：智能上传与处理（Sync & Process）
- US-3.1 放回充电座自动同步
- US-3.2 流量受控（仅 Wi-Fi / 用户许可）
- US-3.3 处理进度可见

### Epic 4：自动 Vlog 生成（Auto Highlight）
- US-4.1 每日自动生成 30–60s Vlog
- US-4.2 风格可选（活力 / 治愈 / 文艺 / 自由）
- US-4.3 一键导出竖版 / 横版
- US-4.4 用户可重新生成 / 微调

### Epic 5：记忆问答（Memory RAG）
- US-5.1 用自然语言搜索过往内容
- US-5.2 跨模态检索（图像 + 语音 + 文本）
- US-5.3 答案附带原始片段证据

### Epic 6：隐私控制（Privacy）
- US-6.1 物理静音键 1 秒生效
- US-6.2 一键删除某天 / 某地点 / 某人
- US-6.3 主动告知周围人正在录制
- US-6.4 数据导出 / 永久注销账号

### Epic 7：分享与社交（Share）
- US-7.1 一键导出到抖音 / 小红书 / Instagram
- US-7.2 导出前自动模糊敏感信息

### Epic 8：设备管理（Device）
- US-8.1 OTA 升级
- US-8.2 电量、存储、温度可视化
- US-8.3 故障自动报告

### 8.2 数据流（典型一天）

```
[早 8:00] 戴上设备 → 触摸传感器检测到佩戴 → 进入待机模式
[早 9:30] 单击按键 → 录制 30s 高光（咖啡店朋友对话）
[午 12:00] 双击 → 连续录制 15min（午餐场景）
[下午] 多次 30s 高光片段
[晚 19:00] 放回充电座 → Wi-Fi 自动同步 → 总数据 ~6GB
[晚 19:05] 云端 Pipeline 触发：
            ├─ 抽帧 → 1,080 关键帧
            ├─ ASR → 4,200 字转录
            ├─ 视觉 → 218 个场景标注
            ├─ 摘要 → 12 个事件聚类
            ├─ 嵌入 → 写入用户向量库
            └─ 自动剪辑 → 45s Vlog (3 种风格)
[晚 19:08] App 推送："今天的 Vlog 已生成"
```
